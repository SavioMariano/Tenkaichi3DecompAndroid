# Dragon Rage PowerVR Fix 0.2 (experimental)
Automatic selects Vulkan again; explicit OpenGL remains available. Retains 0.1 failed-pipeline isolation. All seven failed keys in the supplied Moto G56 log have bit 23 set (no fragment depth output). On PowerVR BXM only, retry failed pipelines with the full depth-output shader when a depth attachment is present and the pass is not a glow/table pass; if still failing, retry with depth clipping. Blend state, write masks and attachments are preserved. Logs report each attempt. These are hypotheses, not a confirmed driver fix. Full depth output and clipping may change depth behavior or performance. BT3_POWERVR_FIX=0 disables retries; =1 enables them for diagnostics. No raw VkResult instrumentation, texture upload changes, JNI fixes or GL optimizations in this revision.
